 ## Hero Section 구현 가이드

첨부된 데스크탑 및 모바일 디자인 레퍼런스를 기반으로 Hero Section을 구현해줘.
실제로 사용된 이미지는 images 폴더에 있는 이미지를 사용해.

### 1. 기본 구조
- 화면 전체를 차지하는 Full-screen Hero Section으로 구현.
- 배경 이미지가 영역 전체를 채우도록 설정하며, 이미지 비율과 관계없이 화면에 자연스럽게 꽉 차도록 처리.
- 배경 이미지 위에 상단 네비게이션과 Hero 텍스트 콘텐츠가 오버레이되는 구조.
- Hero Section은 최소 `100vh` 높이를 확보하도록 구현.

### 2. 반응형 및 미디어쿼리
- Desktop(1440px 기준) → Mobile(813px 이하) 순서로 반응형 CSS를 작성.
- 기본 스타일은 Desktop 기준으로 작성하고, Mobile 스타일은 미디어쿼리로 별도 조정.
- 브레이크포인트: `813px`
- `@media (max-width: 813px)`을 사용하여 모바일 레이아웃으로 전환.
- 단순히 요소 크기만 축소하지 말고, Desktop과 Mobile의 레이아웃 및 콘텐츠 배치 차이를 반영할 것.

### 3. Desktop (1440px 기준)
- 상단 네비게이션: 좌측 로고 및 서브 타이틀, 우측 메뉴 리스트와 검색 아이콘 배치.
- 네비게이션은 Hero Section 상단에 고정된 형태로 배치.
- Hero 텍스트: 좌측 하단 영역에 연도 텍스트 배치, 우측 중앙 영역에 Enter 텍스트 배치.
- 배경 이미지는 가로형 구도에 맞춰 중심 피사체가 화면 중앙~우측에 위치하도록 조정.
- 네비게이션과 텍스트는 배경 이미지 위에 레이어로 배치.

### 4. Mobile (813px 이하)
- Desktop 네비게이션 메뉴를 숨기고 햄버거 메뉴로 변경.
- 상단 중앙에 로고 배치, 좌측에 햄버거 메뉴, 우측에 검색 아이콘 배치.
- Hero 콘텐츠는 Desktop과 다른 배치로 변경.
  - 연도 및 설명 텍스트를 좌측 영역에 세로로 배치.
  - Enter 텍스트는 숨김.
- 배경 이미지는 세로형 화면에 맞게 별도의 위치 및 크기 조정.
- 모바일에서는 배경 이미지의 중심 피사체가 화면 우측에 크게 보이도록 배치.
- 모바일 상단 헤더는 배경 이미지 위에 자연스럽게 오버레이.

### 5. 구현 기술
- CSS `position: absolute` 또는 `position: fixed`를 활용해 Hero 내부 요소를 배경 이미지 위에 배치.
- 배경 이미지에는 `background-size: cover` 및 `background-position`을 활용해 화면 비율에 따른 이미지 크롭 조정.
- 헤더 및 Hero 콘텐츠는 `z-index`로 레이어 순서 관리.
- Desktop / Mobile 간 이미지 위치 차이는 미디어쿼리에서 `background-position`을 별도 지정.
- 로고, 메뉴, Hero 텍스트는 이미지와 독립적으로 관리하여 반응형 레이아웃 변경에 대응.

### 6. 주의사항
- Desktop 디자인을 기준으로 기본 CSS를 먼저 작성하고, Mobile은 미디어쿼리로 덮어쓰는 방식으로 구현.
- 기존 HTML 구조와 CSS를 최대한 유지하며 필요한 부분만 수정.
- 불필요한 요소 추가나 디자인 변경 없이 레퍼런스의 레이아웃과 비율을 최대한 유지.

[ 메뉴 바이브 코딩 프롬프트(모바일) ]
모바일 화면의 햄버거 메뉴 인터랙션을 아래 요구사항에 맞게 구현/수정해줘.

1. **메뉴 등장 애니메이션 및 크기 변경**
   - 첨부된 이미지의 기존 방식(왼쪽에서 오른쪽으로 슬라이드 및 오퍼시티 효과)을 변경할 것.
   - 햄버거 버튼 클릭 시 메뉴가 **상단에서 아래로 슬라이드다운** 되며 나타나도록 구현할 것.
   - 메뉴의 전체 높이는 **화면 높이의 80% (`height: 80vh`)**로 지정할 것.

2. **메뉴 구조 및 주석 처리**
   - 첨부 이미지에 있는 전체 메뉴 구조(`HOME`, `PROJECTS`, `MAGAZINE`, `EXHIBITION`, `INDEX`, `ARCHIVE`)를 동일하게 유지할 것.
   - 단, `PROJECTS` 하위의 세부 메뉴 항목들(`All`, `Product`, `Mobility`, `Spatial`, `Interaction`)은 추후 쉽게 수정할 수 있도록 코드 내에 작성하되, **주석 처리(Comment-out)**하여 현재 화면에는 보이지 않도록 숨겨둘 것.
